## 📝 소개
이 프로젝트는 **React**를 기반으로 제작된 웹사이트로,  
사용자 친화적인 UI와 반응형 레이아웃을 통해 다양한 기기 환경에서 최적의 경험을 제공합니다.


**주요 기능**
- 간단한 페이지 네비게이션 및 콘텐츠 표시
- JSON 연동 데이터 표시 (Axios 활용)
- Swiper를 이용한 슬라이드 UI 구현
- SoundTrack 및 애니메이션 효과

<br />

## 🚀 설치 및 실행 방법

```bash
# 레포지토리 클론
git clone https://github.com/사용자명/레포명.git

# 패키지 설치
npm install

# 로컬 실행
npm start
```
